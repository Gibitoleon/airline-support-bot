# Baggage Service Desk Procedure

## Purpose

This procedure guides customer service agents when assisting passengers with delayed, lost, or damaged baggage.

## Procedure

When a passenger reports a baggage issue, the agent should:

1. Confirm the passenger's booking and identity.
2. Request the baggage tag number and flight details.
3. Check whether a baggage report has already been created.
4. Create or update the baggage report where required.
5. Provide the passenger with the baggage file reference number.
6. Explain the next steps and expected communication process.

## Escalation

Escalate the case when:

- The baggage cannot be located through normal tracing procedures.
- The passenger reports valuable or sensitive items missing.
- The passenger requests compensation.
- The case involves suspected baggage mishandling or security concerns.

Agents should not promise a specific compensation amount without authorization.
